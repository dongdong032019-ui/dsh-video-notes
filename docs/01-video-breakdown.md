## 六步动作（视频原样）

1. 装 DSH Desktop → 启动 → 配模型 → 左下角能看到余额即通
2. 逛插件市场 → 搜索 → 一键装
3. 手机远控：左侧“远程控制” → 装 Agent Anywhere Windows 端 → 手机 App → 扫码
4. 视觉理解：会话底部切到多模态模型 → 直接拖图提问
5. 接 Agnes：注册取 key → 让 agent 读官方文档自己接
6. 接 AnySearch：注册取 key → 跑一条插件安装命令 → 把 key 写进凭据

## 画面里暴露的坑

| 坑 | 证据 | 正确做法 |
|---|---|---|
| Agnes key 401 | 演示里 agent 先打 `api.agnes-ai.com`，回 `401 Invalid token`，误判为 key 坏 | 中国站 base 是 `https://api.agnes-ai.cn`；`.com` 不适用于该类 key |
| 权限墙 | 对话里出现“权限我给你放开了，你再试试” | 接入阶段需要文件+网络权限，接完再收回 |
| 版本口径 | 标题栏 `v2.0.15` | 同一产品线内不同小版本菜单名会变，照界面实际字样走 |
| “生视频也免费” | 口播 3:22–3:30 | 官方定价：图片 ¥0；视频按秒计费 |
| “7 个必装插件” | 6:16 的 HTML 是 agent 现搜现生成的 | 当社区经验看，逐个核对用途再装 |

## 结论

“满配”不是装得越多越好，而是**四类缺口各补一个最省事的方案**：看（模型原生）、画（外部生图/生视频 API）、查（换搜索 provider）、遥控（独立 App 或内建桥接）。装多了只会互相抢资源。
